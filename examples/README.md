# 📂 Examples

`pages/` holds eight saved pages for a fictional CRM brand (`BrightCRM`, domain `brightcrm.example`). The
brand and all text are made up. Built in on purpose: a print version that is an exact copy (with a canonical),
a "small business" page that copies the "small teams" page with a few words changed, two city pages from one
template, two blog posts that share two paragraphs, and a thin About page.

```bash
near-duplicate-finder examples/pages
```
